- `G3misplaced`: HEURISTIC: a def in a standalone object (no class/trait/enum/type of that name beside it) whose first explicit parameter has a project type
- `G9prefix`: type `<Entity><Property>` while a top-level (or same-owner) type `<Entity>` exists in the same module
- `G9prefixRole`: as G9prefix, but the suffix is a role word (Suite, Repo, Service, Row, Markdown, ...)
- `G44`: Iron `.value`, or a newtype built with apply/applyUnsafe/assume/option/either, outside the newtype's companion and outside boundary files
- `G44conversion`: the same inside a *Controller(s)/*Routes file where the value feeds a domain newtype constructor/parse directly, or the construction itself
- `G44plaindef`: a public def with a String/Int/Long/Double/Boolean parameter that some call site feeds with `.value` of a newtype (reported at the def)
- `G45boundary`: hand `.value` or newtype construction inside a boundaries.tsv file (G45: lift type classes instead)
- `G46`: `type X = a.B.C` immediately followed by `val X: a.B.C.type = a.B.C`
- `G47root`: each `_root_` occurrence
- `G47fqn`: a reference spelled `com.histmersion.` (or `_root_.com.histmersion.`) inside a com.histmersion file, outside imports/package clauses; same-package or other-package
- `G47self`: `T.Member` (name-qualified) or `a.b.T.Member` (full-path) written inside T or its companion
- `G47package`: a file with one `package com.histmersion.x.y` clause instead of chained clauses
- `G48`: `.modify(_.x)(_.description(...))` on a Tapir Schema (one per modify)
- `G49`: `.value` inside a lambda passed to a collection operation, as an argument of contains/indexOf, or in `a.value == b.value` / `.value.equalsIgnoreCase(...)`
- `silentCompare`: ==/!=/contains/indexOf whose sides have unrelated types (opaque newtype vs primitive, two newtypes, enum vs primitive/newtype)
- `silentInterp`: an enum value interpolated into s"...", sql"..." or another interpolator
- `silentPure`: X.option/X.either on a newtype whose constraint is Pure (always succeeds)

Counted by the rule (no finding emitted):

- `comparison-side-type-unresolved`: 1949 occurrence(s), e.g. `modules/core/src/test/scala/com/histmersion/api/MergeFixture.scala:178`
- `contains-receiver-element-unresolved`: 225 occurrence(s), e.g. `modules/core/src/test/scala/com/histmersion/util/ocr/ChunkerSuite.scala:71`
- `interpolation-arg-type-unresolved`: 4892 occurrence(s), e.g. `modules/core/src/test/scala/com/histmersion/util/jobs/JobControlRulesSuite.scala:105`
- `value-receiver-type-unresolved`: 1997 occurrence(s), e.g. `modules/core/src/test/scala/com/histmersion/util/jobs/JobControlRulesSuite.scala:41`

Observed while building the rule:

- Receivers whose type SemanticDB cannot give (generic results, tuple-pattern lambda parameters, chained calls on inferred types) leave `.value` unattributed: such rows say `value:?`, and the own-companion check then accepts any enclosing newtype companion.
- Comparisons, `contains` receivers and interpolation arguments with an unresolved type are not classified (counts above); silentCompare and silentInterp are lower bounds.
- silentCompare reports type unrelatedness, not runtime falseness: Iron opaque types erase to their base, so `List[Kind.All].contains("people")` or `Name == Strategy` over the same base can still be true at runtime.
- G44conversion labels every newtype construction inside a *Controller(s)/*Routes file, including output values built there (messages, details), not only api->domain conversions.
- G49 counts every `.value` anywhere inside a lambda passed to a collection operation, including large Tapir `.map { case (...) => ... }` tuples, not only the predicate.
- Overlaps: every G49 `.value` is also a G44/G45boundary row; G44plaindef call sites are G44 rows; alias pairs and `extends _root_.io.github.iltotore.iron.RefinedType[_root_...]` lines feed G46, G47root, G47fqn and G47self at once; a G47self full-path reference is also a G47fqn row.
- Literal construction `X("...")` (checked at compile time) is a G44 `construct:X.apply;literal` row; most G44 test rows are of this shape.
- G3misplaced is a heuristic: it includes `*Markdown` renderer objects (G36), test helper objects and objects in boundary files; an object extending a trait is not excluded.
- G9prefixRole versus G9prefix is decided by a suffix word list (Suite, Repo, Service, Row, Markdown, ...); the entity must be top-level or share the owner.
- Not counted: `.value` of non-Iron members (a case-class field called `value`), the 2 non-Iron `opaque type` declarations, Chimney/chimney-iron transformations, and `.value` in Scaladoc code examples.
- boundaries.tsv is a proposal generated from API use (magnum `sql"`/DbCodec/JDBC, sttp/java.net.http/fetch, Tapir body declarations, circe/YAML/CSV codec files and upstream parsers, decline, localStorage/history/mount, HOCON readers, ProcessBuilder and java.nio.file I/O, plugin-host adapters); Api.scala and Controllers/Routes files are excluded.
