# Compiled extraction preview

Current preview: `target/approval-extraction-preview-v3`, generated by
`tools/refactor/ApprovalExtractionPreview.scala`. The four-file plan in `v3/plan.tsv`
records source and result hashes. `v3/verification.txt` records successful compilation
against the evaluated server test classpath with Scala 3.10 and `-source:future`.
This checks the definitions together, not their eventual separate module builds.

The preview creates a library-owned SourceApprovalService with database and in-memory
implementations, and a package-private SourceApprovalRepo. The repository's source
record operation returns the inserted ID; the service reads the approval through
ApprovalService.approvalIn on the same supplied connection inside its transaction.
It does not open a second transaction or expose the engine repository outside its
package. Source.Status and Edge.Kind remain typed and library-owned.

The existing atomic insertion operation moves to AutomationState.insertApproval and
is shared by engine and library implementations. This retains one implementation of
the state update and existing conflict predicate behavior. Explicit `this.state`
preserves the captured store when a method also has an ApprovalState parameter.
The generator checks the moved operation remains an AST member of the companion.

The original service's source-specific methods remain in this preparation preview;
there is deliberately no application command for this incomplete batch. No isolation
relationship is counted fixed. Before application the next AST pass must:

- Remove source-specific record/proposedBefore from ApprovalService and AgentRepo,
  and the forwarding record method from Approvals, including obsolete library imports.
- Give SourceProposals a SourceApprovalService; route CurrencyCheckPipeline's
  proposedBefore through that library contribution instead of RunCtx.approvalStore.
- Wire LibraryWorkflows with its existing transactor, a.approvalStore and a.clock;
  adapt TestRuns and the shared database/in-memory test composition similarly.
- Rewire source-proposal test helpers while retaining the same eight test identities
  and assertions, and keep unrelated AgentRepo.record overloads unchanged.
- Compile every modified module and caller, execute the frozen database and in-memory
  baseline, and reconcile all 54 confirmed relationships against the new measurement.

`../tests/baseline.tsv` freezes eight passing tests, four per implementation, with no
skips. The worktree-local PostgreSQL cluster on port 55573 was started for this run
and stopped afterward. Neither preview has changed application files or live data.
The two failed intermediate previews and their correction explanation are retained.
This is rewrite development, not an additional detector refinement round.
