CompilerRepairs:
  Reads positioned diagnostics from EXACTLY the same frozen source/build snapshot.
  Numeric/non-numeric diagnostic boundaries must all terminate message parsing;
  verifies source displays and highlighted spans; uses Scala3 zero-based columns.
  Handles supported E007 constructions/container/tuple/function adapters, primitive

  General nominal same-base conversion is NOT enabled. Existing explicitly reviewed
  boundary permissions must not expand just because compilation is hard.

RepairTypes:
  Default resolver requires qualified canonical Iron/Pure/native bases and stable
  object ownership. Alias lookup is guarded; source index is a locator, not semantic
  proof when files have changed.
  resolveImportedPure proves canonical import/rename/non-rooted bindings, native
  scalar/Array bases, namespace/head/type/term shadows across the frozen AST,
  unknown wildcards and inheritance. Unique whole-source object lookup handles
  renamed RefinedType parents missed by the measurement shape index.
  Refuses instance/local-owned paths; nested enum ownership remains partial.
  Imported resolution is intentionally forbidden for propertyFlowsOnly.

Generated helper/property consolidation:
  Proven generated origin, canonical behaviorless Pure companion, exact base,
  unique owner/source-set/module/platform and a matching property projection.
  Never merge two real model properties just because they have the same base.
  Direct constructor/parameter forwarding and whole typed result/val projections
  have supported shapes. E172 map key/value constraints are both retained;
  conflicting targets veto the entire helper even if one valid use was found.
  Custom constructors/methods/constraints, transformations, unknown provenance,
  ambiguous imports/owners and cross-module reuse without an explicit reviewed
  directed dependency are excluded.

generatedHelperAdapters:
  Immediate implementation owner only, same native scalar base, at least one
  proven non-property generated helper; compatible module/source-set/platform and
  canonical Pure behavior required. Does not merge model concepts globally.

GeneratedValueNames:
  Fixes same-name typed val / generated newtype companion collisions, keeping the
  public val and old type alias while renaming the canonical companion to a fresh
  *Value name. Only its own fully qualified initializer constructors change.
  Given aliases without self-name terms and foreign qualified members are retained.
  Own/unqualified same-name initializer references veto the rewrite.
  Five indexed naming candidates remained unresolved, including lowercase all
  versus uppercase All origin in Source.Section. Do not accept them as exceptions.

Callbacks:
  Scalar adapters belong INSIDE a callback, not around the function object.
  A past implementation made malformed calls and wrapped callbacks themselves.
  Historical repair is guarded by before/after hashes, scope and AST provenance.
  One-placeholder scalar rewriting is supported; uncertain multi-placeholder

nativeScalarOperations:
  Added in c859da7b8. Requires ownerOperationsOnly AND nativeBooleans.

  E134: numeric infix only, exact native overload signatures, literal receiver or

Overlap scheduling:
