# Command line (CLI)

`histmersion` is the command-line front door. It is a **pure HTTP client** of the server: it holds
no database password, and everything it does goes through the same handlers as the web page and the
MCP tools. Every command prints the **same Markdown** the matching MCP tool returns; most take
`--json` for scripts.

- `histmersion --help` lists the commands, `histmersion <command> --help` one command's options.
- `--server <url>` (or `HISTMERSION_SERVER_URL`, or `cli.server-url` in the settings file) points it
  at another server.
- Years are signed integers: 3300 BCE is `-3300`.
- Exit codes: 0 success, 1 a usage error, 2 the server said no, 3 the server cannot be reached.
