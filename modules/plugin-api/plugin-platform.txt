# The plugin platform: the libraries Histmersion provides to plugins, at the versions it ships.
#
# A plugin compiles against them through the `histmersion-plugin-platform` POM in the install's Maven
# repository (`histmersion plugin repo`), as compile-only dependencies, and bundles none of them: the
# server's copy is the one that runs. They are part of the plugin compatibility contract, as the SPI is.
#
# The build takes the list from this file and the versions from the server's resolved class path. When
# a dependency upgrade changes one of them, `PluginPlatformSuite` fails until this file is updated: a
# changed line here is a changed contract, to be named in the release notes, because a plugin built
# against the old version may stop linking.
#
# sconfig, kindlings-sconfig-derivation and iron are also plugin-api's own dependencies (its POM lists them):
# the SPI's signatures name their types (ConfigReader, and since SPI 2 the Iron newtypes Year, Doi, …). JSON is
# jsoniter-scala with Kindlings' derivation and AST, which plugin-api's JSON module (histmersion-json) brings.
#
