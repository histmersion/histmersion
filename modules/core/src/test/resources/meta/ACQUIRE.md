**The one place to look for "what do I need to obtain?"** Everything here is in-copyright or
otherwise un-fetchable by the automated pipeline, so it needs *you* to **buy / borrow / download →
add to Calibre** (or drop a PDF at `raw/papers/<citekey>/paper.pdf`). Once it's in Calibre, tell the
agent — it runs `calibre.py import` / **sync-calibre**, enriches, and compiles it into the wiki.

Grouped by topic. `[ ]` = to get · `[x]` = done. This file *replaces* the old
`books_to_acquire.md` + `sources_to_provide.md` + the acquisition half of `queue_disputed_theories.md`.
