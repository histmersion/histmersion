# Helper-adapter fixture origins

These are synthetic test origins for five generated method parameter types, not
production history. The empty applied plan changes no source. Input and Output
have exact owner-match origins. Unknown has none. Title and Slug are constructor
properties and must never be converted to each other by this mode. Custom has
behavior, Checked has a non-Pure constraint, Count has a different base, and a
Helpers.Input reference is foreign to Excluded's implementation. All six negative
cases must remain outside the plan while the five positive expressions match
expected/Helpers.scala. Runtime assertions check values, empty collections, tuple
producer evaluation once, function producer evaluation once and callback calls.

The first fixture preview made no edits: its unqualified native
base syntax is outside RepairTypes' existing fully-qualified-native safety gate.
The final inputs use that supported qualified shape; no production safety gate or
negative expectation was weakened.
